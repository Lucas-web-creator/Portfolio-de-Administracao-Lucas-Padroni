# Sobre o projeto

Este repositório contém o **portfólio profissional de Lucas Padroni**, desenvolvido para apresentar de maneira estruturada sua formação, competências, conhecimentos e projetos relacionados à área de Administração.

O projeto foi construído com uma proposta que vai além de uma simples página pessoal.

A ideia central é utilizar a própria construção do portfólio como demonstração prática de uma visão profissional que conecta:

> **Administração + Tecnologia + Dados + Projetos + Estratégia + Soluções Digitais**

O portfólio apresenta conhecimentos administrativos por meio de uma interface digital desenvolvida integralmente com tecnologias web fundamentais.

Não se trata apenas de apresentar informações.

O projeto procura demonstrar como conhecimentos de Administração podem ser organizados, estruturados, analisados e transformados em soluções digitais.

---

# Objetivo

O principal objetivo do projeto é construir uma presença profissional própria para apresentação de:

* Formação acadêmica e técnica;
* Conhecimentos administrativos;
* Competências profissionais;
* Projetos práticos;
* Conhecimentos em tecnologia;
* Experiências de desenvolvimento;
* Aplicações de dados;
* Estudos e práticas;
* Capacidade de organização;
* Capacidade de planejamento;
* Visão estratégica;
* Integração entre áreas.

O portfólio também funciona como uma demonstração prática de desenvolvimento web utilizando **HTML, CSS e JavaScript**, sem depender de frameworks para sua estrutura principal.

# Conceito

## Administração com visão tecnológica

A proposta do projeto parte de uma ideia simples:

**A Administração não precisa estar isolada da tecnologia.**

Organização, planejamento, processos, dados, logística, marketing, projetos e estratégia podem ser apoiados por ferramentas digitais e sistemas de informação.

Por isso, o portfólio foi construído para representar uma formação que transita entre diferentes áreas.

```text
                         VISÃO INTEGRADA
                               │
             ┌─────────────────┼─────────────────┐
             │                 │                 │
       ADMINISTRAÇÃO        TECNOLOGIA          DADOS
             │                 │                 │
       ┌─────┼─────┐      ┌────┼────┐       ┌────┼────┐
       │     │     │      │    │    │       │    │    │
```

O resultado é uma identidade profissional que busca conectar conhecimento administrativo com pensamento tecnológico.
